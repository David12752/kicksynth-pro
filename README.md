# KickSynth Pro

The ultimate hybrid kick drum synthesizer.

## Features
- **Hybrid Engine**: Sub-oscillator + 3 Sample Layers.
- **Bezier Envelopes**: Flexible curve control.
- **Intelligent EQ**: Automatic frequency management.
- **AI Generator**: Keyword-based preset generation.
- **WAV Export**: Direct drag-and-drop to DAW.

## Structure
- /core: JUCE C++ DSP Engine.
- /ui: Electron/React Frontend.
- /docs: Documentation and Architecture.
- /assets: Samples and UI components.

## Development
1. Install JUCE and Node.js.
2. Build the core in /core.
3. Run 
pm install in /ui.
